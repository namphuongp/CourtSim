# CourtSim frontend

React + Vite; cấu hình API bằng VITE_API_URL (mặc định http://localhost:5000/api).

- npm ci
- npm run dev
- npm run lint
- npm run build
- npm run test:e2e

Cần Node 22.13+ hoặc 24+. Kiểm thử desktop/mobile dùng Playwright và Edge trên Windows. Xem README ở thư mục gốc để chạy backend, seed và nhập văn bản luật.
